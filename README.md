# 专利与技术秘密档案管理服务

这是一个面向研发机构、法务部门和保密办公室的模块化后端，集中管理专利交底资料、技术秘密载体、移交批次、受控副本签发、查阅借阅、对外披露、归还、合规处置、载体盘点、版本与载体来源、密级库位、泄密事件、登录权限、审计以及可恢复后台任务。项目使用 FastAPI 与 SQLite，所有运行数据保存在单个本地数据库文件中，不依赖另行部署的数据库、缓存或消息队列。

## 已有能力

- 身份与权限：支持引导管理员、登录、会话、用户、角色和细粒度权限。
- 批次与二维码：移交批次保存项目、数量和稳定二维码载荷。
- 档案登记：登记专利交底、工艺文档、源代码介质等资产，保存密级库位和生命周期状态。
- 受控副本签发：一次事务内扣减来源载体、创建副本、记录损耗和版本来源事件。
- 查阅借阅归还：保存查阅用途、到期时间、部分归还和最终归还状态。
- 对外披露登记：使用幂等键登记合作方、披露范围和载体消耗，防止重复请求二次扣减。
- 位置脱敏：普通权限只能看到受限库位的替代码，授权人员可查看精确位置。
- 双人审批：合规处置、敏感库位解密等高风险操作要求申请人与审批人分离，并累计不同审批人的决定。
- 泄密事件追踪：事件可以关联档案或移交批次，保存严重度、调查状态和处置结果。
- 泄密事件处置：一封线索可关联多个档案、登录会话与受控副本并立即冻结；支持隔离快照、分派调查人、追加证据与时间线；误报或整改完成后分别解除限制；重复上报自动合并；服务恢复后按事件状态重建限制。
- 审计与任务：关键身份及业务操作留痕，后台任务支持去重、领取与完成。

## 泄密事件处置流程

`POST /api/incidents` 上报线索（`clue_key` 标识同一封线索，如邮件 Message-ID）：

1. **立即冻结**：关联档案/副本（`dossier_id`）或登录会话（`session_id`）后，涉事档案及其仍在流转的副本立即转为隔离状态并保存隔离快照（含冻结前状态与完整性摘要），关联会话立即吊销。重复上报同一 `clue_key` 会合并进既有事件（新增关联、升级严重度），不会产生第二起事件。
2. **隔离期间**：新的借阅、披露、受控副本签发与合规处置请求会被拒绝并返回明确原因（事件编号与说明）；调查组通过 `POST /api/incidents/{id}/assignments` 分派后，无需解除隔离即可在工作区查看并追加证据（`.../evidence`）与时间线（`.../timeline`）。证据与时间线只追加不删除，删除接口所需的 `incidents.evidence.purge` 权限刻意不授予任何内置角色。
3. **解除限制**：确认误报（`POST .../dismiss`）或完成整改（`POST .../resolve`）后分别解除对应限制，档案恢复冻结前状态；会话吊销不可恢复，需重新登录。也可用 `POST .../links/{link_id}/release` 提前解除单个档案的隔离。
4. **服务恢复**：应用启动时及 `POST /api/incidents/rebuild` 会按事件状态重建限制——未结案事件重新隔离并吊销会话，已结案事件解除遗留隔离。

## 运行环境

- Python 3.11
- SQLite 3，由 Python 标准库提供
- Linux、macOS 或 Windows

## 安装

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -e ".[dev]"
```

默认数据库位于 `./data/archives.db`，可用 `ARCHIVE_DATABASE_PATH` 指定其他路径。

## 初始化与完整性检查

```bash
python -m app.cli init-db
python -m app.cli check-db
```

## 启动 API

```bash
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

## 测试

```bash
python -m pytest
```

## 编译检查

```bash
python -m compileall -q app tests
```

## API 冒烟

```bash
python -m app.cli smoke
```
